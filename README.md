# Hockey Parent DJ 🏒🎵

An iOS app (React Native / Expo) for running music during a hockey game off
**Apple Music**. Built for the bench: big tap targets, dark UI, one-tap goal
songs, and a full-screen now-playing view you can read from across the rink.

## Features

- **Playlists** grouped by category (Warmups, In Game, Intermission, End of
  Game, Uncategorized).
- **Shuffle** — randomize a playlist's play order each time you hit play.
- **Auto-advance + skip** — a playlist plays straight through; a **next** button
  (and the full-screen view) lets you jump to the next track on demand.
- **Clip window** — set a start/stop time per song so you only play the good part.
- **Fade in / out** — ramp volume up at the start and down at the stop point.
- **Full-screen now playing** — a big, glanceable takeover with play/pause,
  stop, next, and an elapsed clock; minimizes to a compact bar.
- **Roster + goal songs** — import your roster, assign each kid a song, then tap
  their name on the **Goal Board** when they score and it fires instantly.
- **AI playlist generation** — describe a vibe and Claude picks real songs,
  finds them on Apple Music, and suggests a hype-clip start/stop for each.
- **AI clip suggestions** — one tap in the song editor asks Claude for a
  high-energy start/stop window (plus fades) for any song.

## How it plays music

The app streams audio itself through **Apple Music (MusicKit)** — so *it* owns
the iOS now-playing session (lock screen / Dynamic Island / Control Center).
Things worth knowing:

- Requires an **active Apple Music subscription** on the device and **iOS 16+**.
- Authorization is a native system prompt tied to the app's bundle ID and is
  **persistent** — no hourly re-auth, no token backend to run.
- Start/stop and seeking are exact. **Fades ramp the phone's output volume**
  (MusicKit exposes no per-app volume control) — which is exactly what reaches
  the PA when the phone is plugged in. Set the phone volume to your desired peak.

## Requirements

- A **paid Apple Developer Program** membership.
- The **MusicKit App Service** enabled on the App ID `com.hockeyparentdj.app`
  (required for catalog search).
- An **Apple Music subscription** on the test device.
- A Mac with Xcode to build to a physical iPhone.

## First-time setup

### 1. Build & run on a device

Apple Music playback needs native modules, so Expo Go won't work — build a
custom dev client to a real iPhone. Debug builds currently fail on
RN 0.86 + Xcode 26, so build the **Release** configuration:

```bash
npm install
npx expo run:ios --configuration Release --device "Chris iPhone"
```

`ios/` is gitignored and regenerated by prebuild; delete it (`rm -rf ios`) to
force a clean regeneration. A Release build embeds the JS bundle, so once
installed the app runs standalone (no Mac/Metro needed) — it just needs internet
and Apple Music at game time. A dev-signed build lasts about a year on a paid
account.

Open the app → **Settings → Connect Apple Music** → approve the system prompt.

### 2. (Optional) AI features

AI playlist generation and clip suggestions call a small backend that proxies
requests to Claude so the Anthropic API key stays server-side. See
[`server/README.md`](server/README.md) for deploying it on Railway. Point the
app at it in `app.json`:

```json
"extra": {
  "aiBackendUrl": "https://YOUR-DOMAIN.up.railway.app"
}
```

The AI buttons hide themselves when `aiBackendUrl` is empty, so the app works
fine without a backend — you just add songs by hand.

## Adding songs

Open a playlist → **+ Add Song** and **search the Apple Music catalog** right in
the app. Pick a result and it's added with its title, artist, artwork, and
duration. Or generate a whole playlist with AI and edit from there.

## Notes

- The AI clip suggestion is based on Claude's knowledge of a song's structure,
  **not** audio analysis — Apple Music's DRM streams give no access to raw
  samples. A failed suggestion just leaves the song full-length.
- Secrets (the Anthropic API key) live **only** server-side in Railway
  Variables — never in `app.json` or anywhere the app bundle can read them.
